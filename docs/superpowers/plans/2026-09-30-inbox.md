# Inbox Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every item schoolwork-check posts to `POST /api/agent/inbox` is kept with what Note decided about it and why, shown in the Memory tab next to the memories it produced, and the user can ask the host to sync again from a Refresh button.

**Architecture:**
- A new `inbox_items` table holds one row per `(user_id, source_id)`. `agent_inbox` upserts the row before the session runs, and the `inbox_decide` tool writes the outcome, reason and time in the same transaction as the memories.
- A new `server/src/inbox.rs` holds the data functions and the `/api/inbox` routes: list, read (joined to `memory_sources`) and refresh. Refresh writes a timestamp to the file named by `[inbox] refresh_signal`.
- On the host, a systemd path unit watches that file and starts `schoolwork-check.service`, so Note gains no privilege.
- The web client adds an **Inbox** segment to the Memory tab's filter. It shares the list/detail panes and shows a Refresh button with a spinner that polls for up to 60 s.

**Tech Stack:** Rust 2021, axum 0.8, rusqlite 0.40 (bundled SQLite), jiff 0.2, React 19 + TypeScript, vitest, NixOS modules.

**Spec:** `docs/superpowers/specs/2026-09-30-postits-inbox-focus-connections-design.md`, section **2. Inbox** only. The other groups in that spec have their own plans and are out of scope here.

**Branch:** `inbox`, created from `main` (use superpowers:using-git-worktrees).

**Dependency on voice-calls:** The file lives in `/run/note`, which is the note service's `RuntimeDirectory`. The `voice-calls` branch adds `RuntimeDirectory = "note"` and `RuntimeDirectoryMode = "0750"` to `nix/module.nix`. Task 4, Step 9 checks `main` and adds those two lines on this branch only if they are not there yet. Task 1 has the same kind of check for the migration number.

## Rulings on points the spec leaves open

1. **Title.** The title is the first line of the context that is not blank, trimmed and cut to 200 characters. A context with no such line takes the `source_id` as its title.
2. **When the row is written.** The row is upserted after validation, the daily-cap check and the talk gate. An item refused with 400, 422 or 429 is not kept, because the sender retries it.
3. **Re-sends.** A re-send overwrites `kind`, `title`, `body` and `received_at`, and clears `outcome`, `reason` and `decided_at`. The row reads as undecided until the new session decides. If that session fails, the memories from the previous decision stay (the tool is what supersedes them), and the detail still lists them.
4. **Cursor.** `before` is strict (`received_at < before`). Rows are ordered by `received_at DESC, id DESC`. `limit` defaults to 50 and is clamped to 1–100.
5. **Where the section lives.** The section is a fourth segment, **Inbox**, in the Memory filter.
   - The segment appears only once the user has at least one inbox item.
   - It shares the Memory list/detail panes.
   - The search field is hidden while it is selected.
   - A memory link in an item's detail switches to **All** and opens that fact.
6. **Refresh access.** Refresh is open to any signed-in session (cookie). The signal is host-wide. Any write failure answers `503 {"error":"refresh is unavailable"}` and is logged as `inbox_refresh_error`.
7. **End of the spinner.** The spinner ends when `latest > requested_at` (both server stamps), or when 60 s have passed. Either way it shows "Up to date" for 4 s, then the latest arrival time again.

## Review Focus

1. **A re-sent item whose new session fails.** The row must read as undecided, with the new title and body, and the facts from the previous decision must stay in place and still be listed. Pinned in Task 2 (`a_failed_re_send_leaves_the_item_undecided_and_its_facts_in_place`).
2. **`/run/note` is missing** (RuntimeDirectory not deployed yet, or note restarted without it). Refresh must answer 503 with an error body instead of pretending to work, and must log the failure. Pinned in Task 4 (`refresh_into_a_missing_directory_is_503`).
3. **Nothing arrives after a press** (schoolwork-check fails, or the path unit is absent). The spinner must stop at 60 s, not spin forever. An arrival before 60 s must stop it at once. Pinned in Task 5 (`refreshSettled` tests).
4. **Another user's inbox id, or a non-numeric one.** Either must be indistinguishable from a missing item (404), and another user's rows must never be listed. Pinned in Task 3 (`another_users_item_is_not_found_and_not_listed`).
5. **A blank, whitespace-only or very long multibyte first line.** The title must fall back to the source id, or be cut at 200 characters without a panic. Pinned in Task 1 (`title_is_the_first_non_blank_line_cut_to_200_chars`).

```rust
use rusqlite::{Connection, OptionalExtension};
use serde::Serialize;
use std::path::Path;

pub const KINDS: [&str; 2] = ["announcement", "material"];
pub const LIST_LIMIT_DEFAULT: usize = 50;
pub const LIST_LIMIT_MAX: usize = 100;
const MAX_TITLE_CHARS: usize = 200;

#[derive(Debug, Serialize, PartialEq)]
pub struct InboxRow {
    pub id: i64,
    pub source_id: String,
    pub kind: String,
    pub title: String,
    pub received_at: String,
    pub outcome: Option<String>,
}

#[derive(Debug, Serialize, PartialEq)]
pub struct ProducedMemory {
    pub id: String,
    pub summary: String,
    pub archived: bool,
}

#[derive(Debug, Serialize)]
pub struct InboxItem {
    pub id: i64,
    pub source_id: String,
    pub kind: String,
    pub title: String,
    pub body: String,
    pub received_at: String,
    pub outcome: Option<String>,
    pub reason: Option<String>,
    pub decided_at: Option<String>,
    pub memories: Vec<ProducedMemory>,
}

/// Fixed-width UTC, so stored times sort as text and a client can compare them
/// as strings.
pub fn stamp(ts: jiff::Timestamp) -> String {
    format!("{ts:.6}")
}

/// The first non-blank line of the context, or the source id when it has none.
pub fn title_of(context: &str, source_id: &str) -> String {
    let line = context.lines().map(str::trim).find(|l| !l.is_empty()).unwrap_or(source_id);
    line.chars().take(MAX_TITLE_CHARS).collect::<String>().trim_end().to_string()
}

/// A re-sent source keeps its row and reads as undecided until its new session
/// decides.
pub fn upsert(
    conn: &Connection,
    user_id: i64,
    source_id: &str,
    kind: &str,
    context: &str,
    now: jiff::Timestamp,
) -> rusqlite::Result<i64> {
    conn.query_row(
        "INSERT INTO inbox_items (user_id, source_id, kind, title, body, received_at)
         VALUES (?1, ?2, ?3, ?4, ?5, ?6)
         ON CONFLICT (user_id, source_id) DO UPDATE SET
             kind = excluded.kind,
             title = excluded.title,
             body = excluded.body,
             received_at = excluded.received_at,
             outcome = NULL,
             reason = NULL,
             decided_at = NULL
         RETURNING id",
        (user_id, source_id, kind, title_of(context, source_id), context, stamp(now)),
        |r| r.get(0),
    )
}

pub fn record_decision(
    conn: &Connection,
    user_id: i64,
    source_id: &str,
    outcome: &str,
    reason: &str,
    now: jiff::Timestamp,
) -> rusqlite::Result<()> {
    conn.execute(
        "UPDATE inbox_items SET outcome = ?3, reason = ?4, decided_at = ?5
         WHERE user_id = ?1 AND source_id = ?2",
        (user_id, source_id, outcome, reason, stamp(now)),
    )?;
    Ok(())
}

/// Newest first; `before` is a stamp and is exclusive.
pub fn list(
    conn: &Connection,
    user_id: i64,
    before: Option<&str>,
    limit: usize,
) -> rusqlite::Result<Vec<InboxRow>> {
    let mut stmt = conn.prepare(
        "SELECT id, source_id, kind, title, received_at, outcome FROM inbox_items
         WHERE user_id = ?1 AND (?2 IS NULL OR received_at < ?2)
         ORDER BY received_at DESC, id DESC
         LIMIT ?3",
    )?;
    let rows = stmt.query_map((user_id, before, limit as i64), |r| {
        Ok(InboxRow {
            id: r.get(0)?,
            source_id: r.get(1)?,
            kind: r.get(2)?,
            title: r.get(3)?,
            received_at: r.get(4)?,
            outcome: r.get(5)?,
        })

    conn.query_row(
        "SELECT MAX(received_at) FROM inbox_items WHERE user_id = ?1",

/// The memories are the ones the source holds now; a memory whose file is gone
/// is left out.
pub fn get(
    conn: &Connection,
    data_dir: &Path,
    username: &str,
    user_id: i64,
    id: i64,
) -> anyhow::Result<Option<InboxItem>> {
    let item = conn
        .query_row(
            "SELECT id, source_id, kind, title, body, received_at, outcome, reason, decided_at
             FROM inbox_items WHERE user_id = ?1 AND id = ?2",
            (user_id, id),
            |r| {
                Ok(InboxItem {
                    id: r.get(0)?,
                    source_id: r.get(1)?,
                    kind: r.get(2)?,
                    title: r.get(3)?,
                    body: r.get(4)?,
                    received_at: r.get(5)?,
                    outcome: r.get(6)?,
                    reason: r.get(7)?,
                    decided_at: r.get(8)?,
                    memories: Vec::new(),
                })
            },
        )
        .optional()?;
    let Some(mut item) = item else {
        return Ok(None);
    };
    let ids: Vec<String> = conn
        .prepare(
            "SELECT memory_id FROM memory_sources WHERE user_id = ?1 AND source_id = ?2
             ORDER BY memory_id",
        )?
        .query_map((user_id, &item.source_id), |r| r.get(0))?
        .collect::<rusqlite::Result<_>>()?;
    for mid in ids {
        if !crate::memory::valid_id(&mid) {
            continue;
        }
        if let Some(f) = crate::memory::read(data_dir, username, &mid)? {
            item.memories.push(ProducedMemory { id: f.id, summary: f.summary, archived: f.archived });
        }
    }
    Ok(Some(item))
}
```

`crate::memory::valid_id` is the existing check that `memory_read` in `api.rs` uses. It keeps a malformed `memory_id` (such as `gone` in the test) from reaching the filesystem. If `valid_id("gone")` is true, `read` returns `Ok(None)` and the result is the same.

```rust
    s.as_deref().map(str::trim).filter(|s| !s.is_empty())

async fn list_route(
    user: CurrentUser,
    State(state): State<AppState>,
    Query(q): Query<ListQuery>,
) -> Response {
    let limit = match non_blank(&q.limit) {
        Some(raw) => match raw.parse::<usize>() {
            Ok(n) => n.clamp(1, LIST_LIMIT_MAX),
            Err(_) => return bad_request("limit must be a number"),
        },
        None => LIST_LIMIT_DEFAULT,
    };
    let before = match non_blank(&q.before) {
        Some(raw) => match raw.parse::<jiff::Timestamp>() {
            Ok(ts) => Some(stamp(ts)),
            Err(_) => return bad_request("before must be a timestamp"),
        },
        None => None,
    };
    let conn = state.db();
    match (list(&conn, user.id, before.as_deref(), limit), latest(&conn, user.id)) {
        (Ok(items), Ok(latest)) => {
            Json(serde_json::json!({ "items": items, "latest": latest })).into_response()
        }
        _ => StatusCode::INTERNAL_SERVER_ERROR.into_response(),
    }
}
```

```rust
/// The host starts a sync when the file changes; Note never runs it itself.
async fn refresh_route(user: CurrentUser, State(state): State<AppState>) -> Response {
    let Some(path) = state.inbox_refresh.clone() else {
        return (
            StatusCode::CONFLICT,
            Json(serde_json::json!({ "error": "refresh is not configured" })),
        )
            .into_response();
    };
    let requested_at = stamp(jiff::Timestamp::now());
    match std::fs::write(&path, format!("{requested_at}\n")) {
        Ok(()) => (
            StatusCode::ACCEPTED,
            Json(serde_json::json!({ "requested_at": requested_at })),
        )
            .into_response(),
        Err(e) => {
            let conn = state.db();
            let _ = crate::log::record(
                &conn,
                Some(user.id),
                "inbox_refresh_error",
                &format!("{}: {e}", path.display()),
            );
            (
                StatusCode::SERVICE_UNAVAILABLE,
                Json(serde_json::json!({ "error": "refresh is unavailable" })),
            )
                .into_response()
        }
    }
}
```

```ts
import type { InboxOutcome } from './types'

export const REFRESH_WINDOW_MS = 60_000
export const REFRESH_POLL_MS = 3_000
export const UP_TO_DATE_MS = 4_000

export function outcomeLabel(outcome: InboxOutcome | null): string {
  return outcome ?? 'pending'
}

// Both times are the server's fixed-width stamps, so text order is time order.
export function refreshSettled(requestedAt: string, latest: string | null, elapsedMs: number): boolean {
  return (latest !== null && latest > requestedAt) || elapsedMs >= REFRESH_WINDOW_MS
}

export function arrivalLabel(iso: string, now: Date): string {
  const at = new Date(iso)
  if (Number.isNaN(at.getTime())) return ''
  if (at.toDateString() === now.toDateString()) {
    return at.toLocaleTimeString(undefined, { hour: 'numeric', minute: '2-digit' })
  }
  return at.toLocaleDateString(undefined, {
    month: 'short',
    day: 'numeric',
    ...(at.getFullYear() === now.getFullYear() ? {} : { year: 'numeric' }),
  })
}

export function mergePage<T extends { id: number }>(current: T[], next: T[]): T[] {
  const seen = new Set(current.map((r) => r.id))
  return [...current, ...next.filter((r) => !seen.has(r.id))]
}
```

```tsx
import { useCallback, useEffect, useRef, useState, type RefObject } from 'react'
import { api } from '../api'
import {
  arrivalLabel,
  mergePage,
  outcomeLabel,
  REFRESH_POLL_MS,
  REFRESH_WINDOW_MS,
  refreshSettled,
  UP_TO_DATE_MS,
} from '../inbox'
import type { InboxItem, InboxKind, InboxOutcome, InboxPage, InboxRow } from '../types'

const PAGE_SIZE = 50

const sleep = (ms: number) => new Promise((resolve) => window.setTimeout(resolve, ms))

export function useInbox(refresh: number, notify: (msg: string) => void) {
  const [page, setPage] = useState<InboxPage | null>(null)
  const [more, setMore] = useState(false)
  const [refreshing, setRefreshing] = useState(false)
  const [upToDate, setUpToDate] = useState(false)
  const [selected, setSelected] = useState<number | null>(null)
  const [item, setItem] = useState<InboxItem | null>(null)
  const pageEra = useRef(0)
  const itemEra = useRef(0)
  const alive = useRef(true)

  useEffect(() => {
    alive.current = true
    return () => {
      alive.current = false
    }
  }, [])

  const load = useCallback(async (): Promise<InboxPage> => {
    const era = ++pageEra.current
    const p = await api.inboxList({ limit: PAGE_SIZE })
    if (era === pageEra.current) {
      setPage(p)
      setMore(p.items.length === PAGE_SIZE)
    }
    return p
  }, [])

  useEffect(() => {
    load().catch(() => undefined)
  }, [load, refresh])

  const loadMore = useCallback(() => {
    if (!page || page.items.length === 0) return
    const last = page.items[page.items.length - 1]
    const era = pageEra.current
    api
      .inboxList({ before: last.received_at, limit: PAGE_SIZE })
      .then((p) => {
        if (era !== pageEra.current) return
        setPage((cur) => (cur ? { ...cur, items: mergePage(cur.items, p.items) } : cur))
        setMore(p.items.length === PAGE_SIZE)
      })
      .catch(() => notify("Couldn't load more. Try again."))
  }, [page, notify])

  const pull = useCallback(async () => {
    setRefreshing(true)
    setUpToDate(false)
    const started = Date.now()
    try {
      const { requested_at } = await api.inboxRefresh()
      let latest: string | null = null
      while (alive.current && !refreshSettled(requested_at, latest, Date.now() - started)) {
        await sleep(Math.min(REFRESH_POLL_MS, Math.max(0, REFRESH_WINDOW_MS - (Date.now() - started))))
        const p = await load().catch(() => null)
        if (p) latest = p.latest
      }
      if (alive.current) setUpToDate(true)
    } catch {
      notify("Couldn't refresh. Try again.")
    } finally {
      if (alive.current) setRefreshing(false)
    }
  }, [load, notify])

  useEffect(() => {
    if (!upToDate) return
    const id = window.setTimeout(() => setUpToDate(false), UP_TO_DATE_MS)
    return () => window.clearTimeout(id)
  }, [upToDate])

  const open = useCallback(
    (id: number) => {
      setSelected(id)
      setItem(null)
      const era = ++itemEra.current
      api
        .inboxRead(id)
        .then((it) => {
          if (era === itemEra.current) setItem(it)
        })
        .catch(() => {
          if (era !== itemEra.current) return
          notify("Couldn't open that item. Try again.")
          setSelected(null)
        })
    },
    [notify],
  )

  const close = useCallback(() => {
    ++itemEra.current
    setSelected(null)
    setItem(null)
  }, [])

  return { page, more, loadMore, refreshing, upToDate, pull, selected, item, open, close }
}

}
```

# Sundial Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** List motion that stays quick at any row count, no zoom when a field is tapped on a phone, a Sky theme that follows the sun, the day following the device's time zone, and a Begin working button with pomodoro round marks.

**Architecture:** Five independent workstreams on one branch (`sundial`). A and B are web-only changes to motion helpers, the refresh path and styles. C adds `web/src/sky.ts` (pure colour maths lifted from the mockup's `sky.js`) and wires it through `theme.ts`, `index.html` and Settings. D adds one setting (`timezone_auto`) to the Rust `UserConfig` and a client hook that saves the device zone. E adds two read-only endpoints (`GET /api/tasks/queue`, `GET /api/sessions/today`) and a `pick` state on the Home face.

**Tech Stack:** Rust (axum, rusqlite, jiff) server under `server/`; React 19 + TypeScript + Vite + GSAP 3.15 web client under `web/` (pnpm). Server tests: `cargo test -p note-server` (in-file `#[cfg(test)]` modules, `crate::db::open_memory()`). Web tests: vitest, added in Task 0.

**Spec:** `docs/superpowers/specs/2026-09-25-sundial-design.md`. Mockups and the reference colour maths: `docs/superpowers/mockups/sundial/` (`sky.js`, `motion.html`).

## Global Constraints

- Follow `CLAUDE.md`: no comments narrating history; comments only where the code cannot say it; self-documenting code gets none.
- Reduced motion: every GSAP helper still returns early under `prefers-reduced-motion: reduce`.
- The web client's every `rem` is `16 * --u`; on a phone `--u` is `1px`, so `1rem` there is 16px.
- Server times are RFC 3339 UTC strings; local days come from the user's saved zone via `crate::triggers::timezone(config_dir, username)` / `user_zone(&state, &user.username)` in `api.rs`.
- Every commit message ends with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- Run `cd web && pnpm exec tsc --noEmit` after every web task and `cargo test -p note-server` after every server task; both must pass before the commit.
- Copy is sentence case, plain verbs, no all-caps labels. Button names carry through: "Begin working", "Start", "Another", "Not now", "Start early", "Use my location", "Forget my location", "Follow this device".

## Review Focus

1. A Tasks list scrolled halfway when it mounts: rows above and below the viewport must be visible at once, only rows in view rise (Task 1 test `waveDelays` excludes rects outside `within`).
2. A row folding away while a websocket reload lands: the reload's FLIP pass must not double-jump the rows below (Task 2's `mark()` before `onGone`; manual check in Task 2 step 6).
3. Sky at a latitude with no sunset in summer (Reykjavík in June): altitude never drops below −10°, the palette stays golden/day and nothing throws (Task 6 test).
4. Device zone not in the server's zone list (e.g. an alias like `Asia/Calcutta`): no save and no toast (Task 10 test of `zoneChange`).
5. Begin working with an empty queue or a failed fetch: the face stays and a toast explains (Task 13 tests for `reasonLine` and the visibility rule; manual check with the audit user, who has no tasks).

- [ ] **Step 3: Implement `wave.ts`**

```ts
// A list arriving as one wave from the top of the screen: each row waits by where
// it sits, the whole wave takes `total`, and rows that are not on screen do not
// animate at all. Returns one delay per rect, null for a rect left out.
export function waveDelays(
  rects: readonly DOMRectReadOnly[],
  within?: DOMRectReadOnly,
  total = 0.24,
): (number | null)[] {
  const seen = rects.map((r) => !within || (r.bottom > within.top && r.top < within.bottom))
  const tops = rects.filter((_, i) => seen[i]).map((r) => r.top)
  if (tops.length === 0) return rects.map(() => null)
  const lo = Math.min(...tops)
  const hi = Math.max(...tops)
  return rects.map((r, i) => (seen[i] ? (hi === lo ? 0 : (total * (r.top - lo)) / (hi - lo)) : null))
}
```

```ts
import { waveDelays } from './wave'

/** Rows arriving in a list: one wave from the top of the screen, a quarter second
 *  long whatever the count; rows off screen are placed without moving. */
export function settle(targets: readonly Target[], y = 6, within?: Element): void {
  const els = live(targets)
  if (still() || els.length === 0) return
  const box = within
    ? within.getBoundingClientRect()
    : new DOMRect(0, 0, window.innerWidth, window.innerHeight)
  const delays = waveDelays(els.map((el) => el.getBoundingClientRect()), box)
  const shown: Element[] = []
  const delay: number[] = []
  delays.forEach((d, i) => {
    if (d === null) return
    shown.push(els[i])
    delay.push(d)
  })
  if (shown.length === 0) return
  gsap.from(shown, {
    autoAlpha: 0,
    y,
    duration: 0.32,
    ease: 'power2.out',
    stagger: (i: number) => delay[i],
    overwrite: 'auto',
    clearProps: 'transform,opacity,visibility',
  })
}
```

- [ ] **Step 1: Rewrite the hook**

```ts
function useRowMotion(root: RefObject<HTMLDivElement | null>, busy: boolean) {
  const tops = useRef<Map<string, DOMRect> | null>(null)

  const read = useCallback(() => {
    const at = new Map<string, DOMRect>()
    const els = new Map<string, HTMLElement>()
    root.current?.querySelectorAll<HTMLElement>('[data-row]').forEach((el) => {
      const key = el.dataset.row as string
      at.set(key, el.getBoundingClientRect())
      els.set(key, el)
    })
    return { at, els }
  }, [root])

  // Called with a folded row at zero height, so rows that already slid up are not
  // moved again by the pass that follows its removal.
  const mark = useCallback(() => {
    tops.current = read().at
  }, [read])

  useLayoutEffect(() => {
    if (busy) return
    const { at, els } = read()
    const was = tops.current
    tops.current = at
    if (was === null) return settle([...els.values()])
    const moves: { el: Element; dx: number; dy: number }[] = []
    const fresh: Element[] = []
    for (const [key, el] of els) {
      const before = was.get(key)
      const now = at.get(key) as DOMRect
      if (before === undefined) fresh.push(el)
      else moves.push({ el, dx: before.left - now.left, dy: before.top - now.top })
    }
    flip(moves)
    settle(fresh)
  })

  return { mark }
}
```

```ts
/** One call, `ms` after the last of a burst. */
export function trailing(fn: () => void, ms: number): () => void {
  let timer: ReturnType<typeof setTimeout> | undefined
  return () => {
    if (timer !== undefined) clearTimeout(timer)
    timer = setTimeout(() => {
      timer = undefined
      fn()
    }, ms)
  }
}

/** Only the newest request's answer counts; an older one resolves to undefined. */
export function latest<T>(): (p: Promise<T>) => Promise<T | undefined> {
  let seq = 0
  return (p) => {
    const mine = ++seq
    return p.then((v) => (mine === seq ? v : undefined))
  }
}
```

```ts
  new Intl.DateTimeFormat('en-GB', { timeZone: zone, hour: '2-digit', minute: '2-digit', hour12: false }).format(date)

// Local sunrise and sunset for the day `date` falls on in `zone`, found by
// scanning at five-minute steps; null where the sun never crosses.
export function sunTimes(date: Date, place: { lat: number; lon: number }, zone: string) {
  const ymd = new Intl.DateTimeFormat('en-CA', { timeZone: zone }).format(date)
  const [y, m, d] = ymd.split('-').map(Number)
  const midnight = Date.UTC(y, m - 1, d) - zoneOffsetHours(new Date(Date.UTC(y, m - 1, d, 12)), zone) * 3600000
  let rise: string | null = null
  let set: string | null = null
  let prev = solarAltitude(new Date(midnight), place.lat, place.lon)
  for (let min = 5; min <= 1440; min += 5) {
    const at = new Date(midnight + min * 60000)
    const alt = solarAltitude(at, place.lat, place.lon)
    if (prev < 0 && alt >= 0 && rise === null) rise = wall(at, zone)
    if (prev >= 0 && alt < 0 && set === null) set = wall(at, zone)
    prev = alt
  }
  return { rise, set }
}
```

```rust
/// Minutes of work in sessions that began today and have ended: wall time less
/// pauses, and for pomodoro less the breaks between rounds.
pub fn focused_today(conn: &Connection, user_id: i64, tz: &jiff::tz::TimeZone, now: jiff::Timestamp) -> rusqlite::Result<u32> {
    let (from, to) = crate::day::bounds(now.to_zoned(tz.clone()).date(), tz);
    let mut stmt = conn.prepare(
        "SELECT started_at, ended_at, paused_ms, mode, break_min, round FROM work_sessions
         WHERE user_id = ?1 AND ended_at IS NOT NULL AND started_at >= ?2 AND started_at < ?3",
    )?;
    let rows = stmt.query_map(rusqlite::params![user_id, from.to_string(), to.to_string()], |r| {
        Ok((r.get::<_, String>(0)?, r.get::<_, String>(1)?, r.get::<_, i64>(2)?, r.get::<_, String>(3)?, r.get::<_, Option<i64>>(4)?, r.get::<_, i64>(5)?))
    })?;
    let mut total_ms: i64 = 0;
    for row in rows {
        let (s, e, paused, mode, brk, round) = row?;
        let (Ok(s), Ok(e)) = (s.parse::<jiff::Timestamp>(), e.parse::<jiff::Timestamp>()) else { continue };
        let mut ms = e.duration_since(s).as_millis() as i64 - paused;
        if mode == "pomodoro" {
            ms -= (round - 1).max(0) * brk.unwrap_or(0) * 60_000;
        }
        total_ms += ms.max(0);
    }
    Ok((total_ms / 60_000) as u32)
}
```

```ts
import type { PlanEvent, QueueEntry, SessionStart } from './types'

// Nothing is on right now: no session, and either no block or one still to come.
export const showBegin = (session: unknown | null, next: PlanEvent | null, wait: string | null): boolean =>
  session === null && (next === null || wait !== null)

const dayWord = (due: string, now: Date): string => {
  const d = new Date(due)
  const days = Math.round((Date.UTC(d.getFullYear(), d.getMonth(), d.getDate()) - Date.UTC(now.getFullYear(), now.getMonth(), now.getDate())) / 86_400_000)
  if (days === 0) return 'today'
  if (days === -1) return 'yesterday'
  if (days === 1) return 'tomorrow'
  if (days < -1) return `${-days} days ago`
  return d.toLocaleDateString(undefined, { weekday: 'long' })
}

export function reasonLine(entry: QueueEntry, following: QueueEntry | undefined, now = new Date()): string {
  const due = entry.task.due_at
  const first =
    entry.reason === 'now' ? "You're already on it."
    : entry.reason === 'overdue' && due ? `Due ${dayWord(due, now)}, so it goes first.`
    : entry.reason === 'urgent' ? 'Marked urgent.'
    : entry.reason === 'due_soon' && due ? `Due ${dayWord(due, now)}, the soonest.`
    : 'Nothing is due soon; this has waited longest.'
  return following ? `${first} Then ${following.task.title}.` : first
}

export function sessionFor(entry: QueueEntry): SessionStart {
  const { task, step, planned_min } = entry
  const index = step ? task.children.findIndex((c) => c.id === step.id) : -1
  return {
    title: task.title,
    task_id: task.id,
    notes: (step ?? task).notes,
    ...(index !== -1 && step && { step_index: index + 1, step_count: task.children.length, step_name: step.title }),
    ...(planned_min !== null && { planned_min }),
  }
}
```

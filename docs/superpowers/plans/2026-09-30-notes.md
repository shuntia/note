# Notes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Quick one-line notes: a `notes` table with `/api/notes`, a plain list with an add input on Today's resting face, and `note_*` chat tools.

**Architecture:**
- A new `server/src/notes.rs` owns the table: `stamp`, `checked_text`, `list`, `get`, `create`, `update`, `delete` and `purge_done`. The `/api/notes` routes in `api.rs` and the tools in `tools/note_ops.rs` are thin layers over it.
- The nightly run deletes notes done more than 7 days ago. This happens in its pre-stage block, next to memory expiry.
- On the web, `web/src/notes.ts` holds pure helpers, which vitest covers, and `web/src/views/Notes.tsx` draws the list.
- `Home.tsx` swaps the resting circle's words for that list. A small start ring stays above it, so the way to start a session does not change.

**Tech Stack:** Rust 2021, axum 0.8, rusqlite 0.40 (bundled SQLite), jiff 0.2, schemars, React 19 + TypeScript, vitest, playwright-core (harness only, already in `web/node_modules`).

**Spec:** `docs/superpowers/specs/2026-09-30-postits-inbox-focus-connections-design.md`, section **3. Notes** only. The other groups have their own plans and are out of scope here.

**Branch:** `notes`, created from `main` (use superpowers:using-git-worktrees).

**Depends on:**
- The Now face plan (`docs/superpowers/plans/2026-09-30-now-face.md`) lands first. It changes `begin`, the strip, Stop and idle inside a session in `Home.tsx`. This plan touches only the resting branch of `bigFace`, the resting face size, one choreography line and one import. If `main` does not yet have `api.candidates` in `Home.tsx`, stop and merge Now first.
- The Idle nudges plan (`docs/superpowers/plans/2026-09-30-idle-nudges.md`) builds on this plan. It reads table `notes(id, user_id, text, pinned, created_at, done_at, last_nudged_at)`, where `done_at IS NULL` means open, `pinned` is 0/1 and times are RFC 3339 UTC text. It inserts with `INSERT INTO notes (user_id, text, pinned, created_at)`. Keep these names and defaults exactly.

## Rulings on points the spec leaves open

1. **"One line, 200 characters."**
   - Runs of whitespace, newlines included, fold to one space, and the ends are trimmed.
   - What is left must be 1 to 200 Unicode scalar values (Rust `chars()`, JS `[...s]`). A byte count would cap Japanese at about 66 characters.
   - The same rule applies on the route, the tools and the web. Anything else is refused with 422 (route) or `rejected` (tool).
2. **Done notes on the wire.**
   - `GET /api/notes` returns the open notes first: pinned ones, then the rest in the order they were added. Notes done in the last 7 days follow.
   - The face draws only the open ones. The undo toast is the way back.
   - "In the last 7 days" means `done_at >= now − 7 days`. The purge deletes `done_at < now − 7 days`, so the two never disagree.
3. **Done twice, and undone.**
   - `done: true` on a note that is already done keeps its first `done_at`, so a second check does not extend its week.
   - `done: false` clears `done_at`.
4. **Tool arguments.**
   - The id field is `note_id`, like `task_id`, `goal_id` and `event_id` everywhere else.
   - `note_update` needs `text`, `pinned` or both.
   - `note_list` returns open notes only.
   - The tools refuse a task-scoped session, as the goal tools do.
5. **The note tools are in Nightly too.** `session_surfaces_nest_and_import_stands_apart` holds Talk ⊆ Nightly, apart from the ask-the-user tools. `dispatch` also uses Nightly membership to tell a `forbidden` tool from an `unknown_tool`. The nightly prompt is unchanged.
6. **The resting face.**
   - With no session running, the face is the notes list. Above it sits a small start ring: the same `circle-face idle` element, with the same `surface` handlers (tap, Enter or Space starts working) and the same faded wait arc and start hint. It is 96 u on the phone and 120 u on the desktop.
   - The next event's words (name, wait, span) leave the face. They still appear in the compact header and the hero, which the scroll lands on.
   - The notes list sits outside the start ring. Taps and keys inside it never start a session.
7. **The menu.**
   - `Overflow` with `trigger={false}` and `row=".note-row"`: right-click or long-press opens it.
   - Items: `Edit`, `Pin` or `Unpin`, `Done`.
   - Editing in place: Enter or blur saves, and Escape cancels. A blank or unchanged edit leaves the note as it was.
   - A pinned note carries a small pin glyph (`aria-label="Pinned"`).
8. **Adding.** The note appears when the server answers; it is not optimistic. On failure the text returns to the input and a toast says so.
9. **The purge** runs in `nightly::run_for_user`'s pre-stage block, next to `memory::archive_expired`. It is not a report stage, so the `nightly_run` line is unchanged. A failure is logged as `notes_purge_error`.
10. **No delete in the web client.** `DELETE /api/notes/{id}` exists for API callers. The face offers done, which comes back through undo.

## Review Focus

1. **Undo pressed before the done request has answered** (a quick check and a quicker Undo on a slow phone connection). The note must end up open on the server and on the face. It must not be left done by the later-arriving first request. Pinned in Task 6: the undo PATCH is chained after the done PATCH, and the harness `undo` check reads the server after an immediate Undo.
2. **Pasted text with newlines, tabs or 200 Japanese characters.** It must be kept as one line, counted in characters, and accepted up to 200. 201 is refused with 422, never cut silently. Pinned in Task 1 (`text_is_one_line_of_at_most_200_characters`), Task 2 (`text_rules_hold_on_the_route`) and Task 5 (`noteText` tests).
3. **Another user's note id through the route or a tool.** It must read as missing (404 / `not_found`), be left unchanged and never be listed. Pinned in Task 1 (`another_users_note_is_out_of_reach`), Task 2 (`another_users_note_is_not_found_and_not_listed`) and Task 4 (`a_note_tool_refuses_what_is_not_a_note`).
4. **Checked off on the phone and again by chat** (`note_done` after a tick). The first `done_at` must stand, so the note is purged a week after it was really done, and a reopen clears it. Pinned in Task 1 (`checking_off_twice_keeps_the_first_time_and_reopening_clears_it`).
5. **Typing in the add input, or tapping a note, with no session running.** It must never start a session, while a tap on the start ring still does. Pinned in Task 6: the harness `startsOnlyFromTheRing` check.

```rust
use crate::tasks::UpdateError;
use rusqlite::{Connection, OptionalExtension};
use serde::{Deserialize, Serialize};

pub const MAX_CHARS: usize = 200;
/// How long a done note stays for undo before the nightly run deletes it.
pub const KEEP_DONE_DAYS: i64 = 7;

/// `done_at` is `None` while the note is open.
#[derive(Debug, Clone, PartialEq, Serialize)]
pub struct Note {
    pub id: i64,
    pub text: String,
    pub pinned: bool,
    pub created_at: String,
    pub done_at: Option<String>,
    pub last_nudged_at: Option<String>,
}

#[derive(Debug, Deserialize)]
#[serde(deny_unknown_fields)]
pub struct NewNote {
    pub text: String,
}

#[derive(Debug, Default, Deserialize)]
#[serde(deny_unknown_fields)]
pub struct NotePatch {
    pub text: Option<String>,
    pub pinned: Option<bool>,
    pub done: Option<bool>,
}

/// Whole-second RFC 3339 UTC, so stamps compare correctly as text.
pub fn stamp(ts: jiff::Timestamp) -> String {
    jiff::Timestamp::from_second(ts.as_second()).expect("a whole second of a valid instant").to_string()
}

/// Folds every run of whitespace to one space; the rest must be 1 to
/// `MAX_CHARS` characters.
pub fn checked_text(raw: &str) -> Result<String, UpdateError> {
    let text = raw.split_whitespace().collect::<Vec<_>>().join(" ");
    let n = text.chars().count();
    if n == 0 || n > MAX_CHARS {
        return Err(UpdateError::Invalid(format!(
            "text must be one line of 1..={MAX_CHARS} characters"
        )));
    }
    Ok(text)
}

fn cutoff(now: jiff::Timestamp) -> String {
    stamp(now - jiff::SignedDuration::from_hours(KEEP_DONE_DAYS * 24))
}

const COLS: &str = "id, text, pinned, created_at, done_at, last_nudged_at";

fn row_to_note(r: &rusqlite::Row) -> rusqlite::Result<Note> {
    Ok(Note {
        id: r.get(0)?,
        text: r.get(1)?,
        pinned: r.get(2)?,
        created_at: r.get(3)?,
        done_at: r.get(4)?,
        last_nudged_at: r.get(5)?,
    })
}

/// Open notes, pinned first and then in the order they were added, followed by
/// the ones done within the last `KEEP_DONE_DAYS`.
pub fn list(conn: &Connection, user_id: i64, now: jiff::Timestamp) -> rusqlite::Result<Vec<Note>> {
    let mut stmt = conn.prepare(&format!(
        "SELECT {COLS} FROM notes
         WHERE user_id = ?1 AND (done_at IS NULL OR done_at >= ?2)
         ORDER BY done_at IS NOT NULL, pinned DESC, id"
    ))?;
    let rows = stmt.query_map((user_id, cutoff(now)), row_to_note)?;
    rows.collect()
}

pub fn get(conn: &Connection, user_id: i64, id: i64) -> rusqlite::Result<Option<Note>> {
    conn.query_row(
        &format!("SELECT {COLS} FROM notes WHERE id = ?1 AND user_id = ?2"),
        (id, user_id),
        row_to_note,
    )
    .optional()
}

pub fn create(
    conn: &Connection,
    user_id: i64,
    new: NewNote,
    now: jiff::Timestamp,
) -> Result<Note, UpdateError> {
    let text = checked_text(&new.text)?;
    conn.execute(
        "INSERT INTO notes (user_id, text, created_at) VALUES (?1, ?2, ?3)",
        rusqlite::params![user_id, text, stamp(now)],
    )?;
    Ok(get(conn, user_id, conn.last_insert_rowid())?.expect("row was just created"))
}

/// `done: true` keeps an existing `done_at`; `done: false` clears it.
/// `Ok(None)` when the note is not this user's.
pub fn update(
    conn: &Connection,
    user_id: i64,
    id: i64,
    patch: NotePatch,
    now: jiff::Timestamp,
) -> Result<Option<Note>, UpdateError> {
    let text = patch.text.as_deref().map(checked_text).transpose()?;
    let changed = conn.execute(
        "UPDATE notes SET
            text = COALESCE(?1, text),
            pinned = COALESCE(?2, pinned),
            done_at = CASE ?3 WHEN 1 THEN COALESCE(done_at, ?4) WHEN 0 THEN NULL ELSE done_at END
         WHERE id = ?5 AND user_id = ?6",
        rusqlite::params![text, patch.pinned, patch.done, stamp(now), id, user_id],
    )?;
    if changed == 0 {
        return Ok(None);
    }
    Ok(get(conn, user_id, id)?)
}

pub fn delete(conn: &Connection, user_id: i64, id: i64) -> rusqlite::Result<bool> {
    Ok(conn.execute("DELETE FROM notes WHERE id = ?1 AND user_id = ?2", (id, user_id))? > 0)
}

/// Deletes this user's notes done more than `KEEP_DONE_DAYS` before `now`.
pub fn purge_done(conn: &Connection, user_id: i64, now: jiff::Timestamp) -> rusqlite::Result<usize> {
    conn.execute(
        "DELETE FROM notes WHERE user_id = ?1 AND done_at IS NOT NULL AND done_at < ?2",
        (user_id, cutoff(now)),
    )
}
```

```ts
import type { Note } from './types'

export const NOTE_MAX = 200

/** The text as the server keeps it (one line, 1–200 characters), or null. */
export function noteText(raw: string): string | null {
  const text = raw.split(/\s+/).filter(Boolean).join(' ')
  const length = [...text].length
  return length > 0 && length <= NOTE_MAX ? text : null
}

/** Open notes, pinned first, then in the order they were added. */
export function openNotes(notes: Note[]): Note[] {
  return notes
    .filter((n) => n.done_at === null)
    .sort((a, b) => Number(b.pinned) - Number(a.pinned) || a.id - b.id)
}

export function withNote(notes: Note[], note: Note): Note[] {
  return notes.some((n) => n.id === note.id)
    ? notes.map((n) => (n.id === note.id ? note : n))
    : [...notes, note]
}
```

```tsx
import { useCallback, useEffect, useRef, useState, type FormEvent } from 'react'
import { api } from '../api'
import type { ToastAction } from '../app'
import { NOTE_MAX, noteText, openNotes, withNote } from '../notes'
import { Overflow, type OverflowItem } from '../overflow'
import { Tick } from '../tick'
import type { Note, NotePatch } from '../types'
import '../styles/notes.css'

const UNDO_MS = 5000

export function Notes({
  notify,
  refresh,
}: {
  notify: (msg: string, action?: ToastAction) => void
  refresh: number
}) {
  const [notes, setNotes] = useState<Note[]>([])
  const [draft, setDraft] = useState('')
  const [editing, setEditing] = useState<{ id: number; text: string } | null>(null)
  const cancelled = useRef(false)

  const load = useCallback(() => {
    api.notes().then(setNotes).catch(() => {})
  }, [])
  useEffect(load, [load, refresh])

  const put = (note: Note) => setNotes((ns) => withNote(ns, note))
  const send = (note: Note, patch: NotePatch, failed: string) =>
    api
      .patchNote(note.id, patch)
      .then(put)
      .catch(() => {
        notify(failed)
        load()
      })

  const done = (note: Note) => {
    put({ ...note, done_at: new Date().toISOString() })
    const sent = api.patchNote(note.id, { done: true }).catch(() => {
      notify("Couldn't check that off. Try again.")
      load()
    })
    notify('Done', {
      label: 'Undo',
      run: () => {
        put(note)
        void sent.then(() => send(note, { done: false }, "Couldn't bring that back. Try again."))
      },
      windowMs: UNDO_MS,
    })
  }

  const pin = (note: Note) => {
    put({ ...note, pinned: !note.pinned })
    void send(note, { pinned: !note.pinned }, "Couldn't pin that. Try again.")
  }

  const keep = () => {
    const edit = editing
    setEditing(null)
    if (cancelled.current || !edit) {
      cancelled.current = false
      return
    }
    const note = notes.find((n) => n.id === edit.id)
    const text = noteText(edit.text)
    if (!note || !text || text === note.text) return
    put({ ...note, text })
    void send(note, { text }, "Couldn't change that note. Try again.")
  }

  const add = (e: FormEvent) => {
    e.preventDefault()
    const text = noteText(draft)
    if (!text) return
    setDraft('')
    api
      .addNote(text)
      .then(put)
      .catch(() => {
        setDraft(text)
        notify("Couldn't add that note. Try again.")
      })
  }

  const items = (note: Note): OverflowItem[] => [
    { label: 'Edit', run: () => setEditing({ id: note.id, text: note.text }) },
    { label: note.pinned ? 'Unpin' : 'Pin', run: () => pin(note) },
    { label: 'Done', run: () => done(note) },
  ]

  return (
    <div className="notes">
      <ul className="notes-list">
        {openNotes(notes).map((note) => (
          <li key={note.id} className="note-row">
            <Tick checked={false} label={`Mark ${note.text} done`} onClick={() => done(note)} />
            {editing?.id === note.id ? (
              <input
                className="note-edit"
                value={editing.text}
                maxLength={NOTE_MAX * 2}
                aria-label={`Edit ${note.text}`}
                autoFocus
                onChange={(e) => setEditing({ id: note.id, text: e.target.value })}
                onBlur={keep}
                onKeyDown={(e) => {
                  if (e.key === 'Enter') e.currentTarget.blur()
                  else if (e.key === 'Escape') {
                    cancelled.current = true
                    e.currentTarget.blur()
                  }
                }}
              />
            ) : (
              <span className="note-text">{note.text}</span>
            )}
            {note.pinned && (
              <svg className="note-pin" viewBox="0 0 24 24" role="img" aria-label="Pinned">
                <path d="M9 4h6l-1 6 3 3H7l3-3-1-6zM12 13v7" />
              </svg>
            )}
            <Overflow
              className="note-more"
              row=".note-row"
              trigger={false}
              label={`More: ${note.text}`}
              items={items(note)}
            />
          </li>
        ))}
      </ul>
      <form className="note-new" onSubmit={add}>
        <input
          value={draft}
          maxLength={NOTE_MAX * 2}
          placeholder="+"
          aria-label="Add a note"
          enterKeyHint="done"
          onChange={(e) => setDraft(e.target.value)}
        />
      </form>
    </div>
  )
}
```

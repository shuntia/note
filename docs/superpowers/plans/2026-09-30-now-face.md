# The Now Face Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A tap on Now starts on today's scheduled block, a paused session can be stopped outright, and a session left alone shows nothing but its timer.

**Architecture:**
- A new `tasks::candidates` reads today's blocks, the ones linked to tasks through `event_tasks`, and returns them as `QueueEntry` rows with `reason: "scheduled"`, the block's length as `planned_min` and the block's `event_id`. The block current or next by the clock comes first.
- A new route, `GET /api/tasks/candidates`, returns those rows, or the priority queue when today has none. The web strip reads only this route, so `begin` and `loadStrip` keep one shape.
- Stop is a round button shown only while paused. It takes the optimistic path that finishing takes: the face clears at once, the end waits in a hold for the undo window, and a toast offers Undo.
- During a session, `useIdle` runs on the phone as well as the desktop. Stylesheet rules keyed on `html.in-session.idle` fade the rest of the face out and then hide it (`visibility: hidden`, `pointer-events: none`). `html.waking` gives the 200 ms fade back. A gesture that begins while idle only wakes the face.

**Tech Stack:** Rust 2021, axum 0.8, rusqlite 0.40 (bundled SQLite), jiff 0.2, React 19 + TypeScript, gsap, vitest, playwright-core (harness only, already in `web/node_modules`).

**Spec:** `docs/superpowers/specs/2026-09-30-postits-inbox-focus-connections-design.md`, section **1. The Now face** only. The other groups have their own plans and are out of scope here.

**Branch:** `now-face`, created from `main` (use superpowers:using-git-worktrees).

## Rulings on points the spec leaves open

1. **`fired` blocks are candidates.** The runner marks a task block `fired` when it starts (`server/src/runner.rs:287-290`). Without `fired`, the block current by the clock would never be a candidate. `done` and `dropped` blocks are not candidates.
2. **Order.** The first candidate is the first block in `wall_time` order whose end is after now: the current block, or else the next one. The later blocks follow in time order, and then the blocks already behind. When every block is behind, the order is plain time order.
3. **One slot per piece of work.** Each linked task or step appears once, and its first block in that order wins. A block is skipped when its task is not `open` or `in_progress`, when its step is `done` or `dropped`, or when the task belongs to someone else.
4. **The fallback is server-side.** `GET /api/tasks/candidates` answers with the priority queue when today has no candidates, so the client makes one request and sees one shape. `GET /api/tasks/queue` is unchanged. The web client's `api.queue` is replaced by `api.candidates`, because nothing else calls it.
5. **Scheduled entries carry their block.** `QueueEntry` gains an optional `event_id`, which is omitted from the JSON when absent. `sessionFor` passes it on, so a start from the strip settles its block on finish, as a start from the day list does.
6. **`planned_min` is the block's raw length in minutes**, at least 1, as `start(ev)` in `Home.tsx` computes it. It is not rounded to 5.
7. **Where Stop sits.**
   - Stop sits under the paused face, 64 u below the circle, clear of the strip's dots. It also sits beside the pause button in the desktop compact header and the phone's pulled arc.
   - The session hint yields to Stop while paused.
   - The toast reads `Stopped` and offers `Undo`.
   - The quick-stop decision is taken when Stop is pressed. The server checks the minute again when the hold sends, up to 5 s later. So a stop at 55–60 s ends the session normally instead of discarding it, which is the same as a delayed swipe.
8. **What "only the timer" keeps.**
   - The arc, its track, the counter and the pause glyph stay.
   - The spec's list goes: beads, the other slots, the current slot's name, sub and hairline, the dots, the hints, the top bar, the phone's tab bar and handle. So do the two controls on the face, the chevron and Stop.
   - The break sheet and the compact header are left alone.
   - In a session the phone's own rested timer (`app.tsx`) stands down, and `html.idle` takes the bar away instead.
9. **A gesture begun while idle only wakes the face.**
   - A pointer gesture does not tap, drag or swipe down, and a horizontal wheel does not move the strip.
   - Keys still act, because a key is never an accident on a phone left on a desk.
   - This applies only in a session. Outside a session, Today keeps its current behaviour.

## Review Focus

1. **A block still `pending` or `fired` after its task (or step) was ticked off elsewhere.** It must never be a candidate, and a second block for the same work must not become a second slot. Pinned in Task 1 (`candidates_skip_settled_work_and_repeat_blocks`).
2. **A user whose zone puts "today" on another UTC date** (Tokyo at 08:30 is 23:30 UTC the day before). Candidates must follow the user's own date and clock, and never show another user's blocks or tasks. Pinned in Task 1 (`candidates_follow_the_users_own_day_and_no_one_elses`).
3. **The first touch on a resting session face** (a phone lying on a desk, a hand reaching for it). It must only wake the face: it must not pause, switch task or finish. Pinned in Task 5 (the harness `idle` run prints `pausedAfterTap: false`).
4. **Stop, then Undo, while a refetch happens inside the undo window** (window focus or a server nudge calls `/api/sessions/open`). The session must come back paused and intact, and must not flash back in before Undo. Pinned in Task 4 (the harness `stop` run prints the session restored after Undo and gone after the window).
5. **Evening, with every block of the day already over but none settled.** The strip must still be built from them, in time order, instead of falling back to the queue. Pinned in Task 1 (`candidates_behind_the_clock_keep_time_order`).

/// Today's blocks laid for tasks and not yet settled, one per task or step, as
/// queue entries: the block current or next by the clock first, then the rest
/// of the day in time order, then the blocks already behind. `planned_min` is
/// the block's own length.
pub fn candidates(
    conn: &Connection,
    user_id: i64,
    tz: &jiff::tz::TimeZone,
    now: jiff::Timestamp,
    limit: usize,
) -> rusqlite::Result<Vec<QueueEntry>> {
    let here = now.to_zoned(tz.clone());
    let minute = i64::from(here.hour()) * 60 + i64::from(here.minute());
    let mut stmt = conn.prepare(
        "SELECT e.id, e.wall_time, e.end_wall_time, et.task_id
         FROM events e
         JOIN plans p ON p.id = e.plan_id
         JOIN event_tasks et ON et.event_id = e.id
         WHERE p.user_id = ?1 AND p.date = ?2 AND e.end_wall_time IS NOT NULL
           AND e.status IN ('pending','snoozed','fired')
         ORDER BY e.wall_time, e.id",
    )?;
    let blocks = stmt
        .query_map((user_id, here.date().to_string()), |r| {
            Ok((r.get::<_, i64>(0)?, r.get::<_, String>(1)?, r.get::<_, String>(2)?, r.get::<_, i64>(3)?))
        })?
        .collect::<rusqlite::Result<Vec<_>>>()?;
    let span = |wall: &str, end: &str| {
        Some((crate::plan::parse_minutes(wall).ok()?, crate::plan::parse_minutes(end).ok()?))
    };
    let first = blocks
        .iter()
        .position(|(_, wall, end, _)| span(wall, end).is_some_and(|(_, stop)| stop > minute))
        .unwrap_or(0);
    let mut seen = std::collections::HashSet::new();
    let mut out = Vec::new();
    for (event_id, wall, end, linked) in blocks[first..].iter().chain(&blocks[..first]) {
        if out.len() == limit {
            break;
        }
        if !seen.insert(*linked) {
            continue;
        }
        let Some((start, stop)) = span(wall, end) else { continue };
        let Some(held) = get(conn, user_id, *linked)? else { continue };
        let (mut top, step) = match held.parent_id {
            Some(parent) => {
                if matches!(held.state.as_str(), "done" | "dropped") {
                    continue;
                }
                let Some(top) = get(conn, user_id, parent)? else { continue };
                (top, Some(held))
            }
            None => (held, None),
        };
        if !matches!(top.state.as_str(), "open" | "in_progress") {
            continue;
        }
        top.pressing = pressing_at(&top.state, top.due_at.as_deref(), now);
        let children = children_of(conn, top.id)?;
        let step = step.or_else(|| children.iter().find(|c| c.state != "done").cloned());
        out.push(QueueEntry {
            task: TaskNode { task: top, children },
            step,
            planned_min: Some(u32::try_from((stop - start).max(1)).unwrap_or(1)),
            reason: "scheduled",
            event_id: Some(*event_id),
        });
    }
    Ok(out)
}

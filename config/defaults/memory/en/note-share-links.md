category: procedural
summary: Note share links: how to let a parent, partner or coach see part of the day and talk to Note without an account
---

A share link lets someone the user trusts chat with Note about part of their day, with no account.

Making one: Settings → Advanced → "Share links" → "New link". Choose who it is for, a brief for Note on how to talk to them, which categories they may see, and what is shared: the plan, tasks, goals, progress, details. "Allow notes" lets them leave the user a message. Also set how many days ahead they see, a daily message limit, and when the link ends.

Managing: copy the link, "Preview as visitor", see its activity, or Revoke it at any time. The visitor's Note sees only what the link allows.

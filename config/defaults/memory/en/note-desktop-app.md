category: procedural
summary: Note desktop app and phone install: using Note outside the browser
---

Phone: open Note in the browser and use "Add to Home Screen" (or Install). It then runs like an app and can receive push notifications.

Desktop: the Note desktop app (Linux, macOS, Windows) opens Note in its own window, with a tray icon that shows or hides it, a "Start at login" option, menus in English or Japanese, and an offline page when the server cannot be reached. There is no download inside the app; the server's admin provides the installer.

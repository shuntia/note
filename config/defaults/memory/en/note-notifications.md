category: procedural
summary: Note notifications: how to turn on push notifications and choose how each task announces itself
---

Turning on: Settings → Notifications → "Push on this phone" (on each phone or browser separately). "Send a test notification" checks it. Tapping a notification opens the conversation it belongs to.

Where notifications go: an open app first, then push, then Matrix if linked. During a quiet calendar entry they wait until it ends.

Per task: each task or block announces itself when it starts in one of three ways: None (silent), Chat (a line in the day's thread), or Notify (a notification, the default). Set it from the task's row menu, a block's "Ping me", or in Chat ("don't ping me for the reading block").

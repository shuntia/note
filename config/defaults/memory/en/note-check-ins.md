summary: Note check-ins: how Note reaches out on its own, idle nudges, and how to change how often
---

Check-ins: routines in the day plan (such as the morning check-in) ask a question in that day's thread in Chat; the user just replies there. They also arrive as a notification, or on Matrix when linked.

Note can also decide to look again later on its own: for example to ask how a task went, or to follow up if there is no reply. It may say something then, or stay quiet if nothing is needed. "Check in with me at 3" in Chat sets one.

How often: Settings → Notifications → "Check-ins from Note a day" sets the daily limit (4 by default). If Note thinks the day needs more, it asks first. The "Check-ins" switch turns routine pings off.

Idle nudges: if the user has been idle for a while (20 minutes by default) and something Note is keeping in mind is still open, it sends one light nudge. Settings → Notifications → "Nudge when idle" sets or disables it. Nudges never come during a work session or a quiet calendar entry, or after the close-the-day time.

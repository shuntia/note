category: procedural
summary: Note voice calls: how to call Note by phone through Matrix/Element X, and have Note ring you
---

Setup: link a Matrix account first (Settings → Connections → Matrix). Calls then work in Element X.

Calling Note: start a voice call in the Element X chat with Note. Note picks up within a couple of seconds and waits for the user to speak first. It answers in the language the user speaks (English or Japanese). Anything that works in Chat works on a call: adding tasks, checking the plan, looking things up. Lookups run in the background while the talk goes on, and the user can interrupt Note at any time. Say goodbye, or "that's all", to end the call; Note says goodbye and hangs up. Calls end after 30 minutes.

Note ringing the user: Settings → Connections → Calls → "Ring me for" chooses Pressing, Check-ins or Never; "Ring me" tests it. The same section picks Note's voice (tap one to hear a sample) and turns the ready sound on or off.

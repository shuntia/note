category: procedural
summary: Note memory: what Note remembers about the user, how to see it, and how to correct it or make Note forget
---

What Note remembers: lasting facts (people, courses, routines, preferences, decisions), a summary of every conversation, a summary of each week, and what came in through the inbox. It learns from conversations each night, and dated facts (a quiz on the 25th) expire on their own.

Seeing it: the Memory tab lists what Note knows, with filters (All, Facts, Episodes, Inbox) and a search box ("Search what Note knows"). Open a fact to read it.

Correcting: say "that's wrong, it's actually…" or "remember that I…" in Chat, or press "That's wrong" or "Tell Note more" on a fact. To forget, say "forget that". Note replaces the fact; the old version is archived rather than deleted, and no longer used.

Note also knows how it works itself, so "can you…?" or "how do I…?" can be asked any time.

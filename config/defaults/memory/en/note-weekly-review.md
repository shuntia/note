summary: Note weekly review: the Monday letter about the past week
---

Every Monday morning, shortly after the morning debrief, Note sends a short letter called "Your week": what the week was, two or three things that went well, one pattern it noticed, and one small thing to try next week. It is never a scold or a tally. It arrives on its own; there is nothing to set up.

Note also remembers each week, so "how did last week go?" can be answered in Chat.

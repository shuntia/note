category: procedural
summary: Note inbox: connected feeds (course site, school, workspace, mailing list) and what Note does with each item
---

The inbox collects items from connected sources such as a course site, a school portal, a team workspace or a mailing list. It is in the Memory tab under "Inbox", with a refresh control.

For each item Note decides one thing: remember it (it keeps the useful facts, such as dates, rules and where to find things, and lets dated ones expire), make it a task (assignments become tasks with a due date, size and steps), or ignore it. Each item shows which it got. An updated item replaces what Note took from it before.

Connecting a feed: there is no connect button in the app. A feed is sent in by an importer script using an API token, made in Settings → Advanced → "API tokens". The server's admin sets up importers.

summary: Note invites (admins): how to invite someone to Note and what happens when they join
---

Only admins can invite.

Making an invite: Settings → Admin → Admin panel (it asks for a passkey or authenticator code) → Invites → "New invite link". Optionally suggest a username, make them an admin, and choose how many days it stays open (7 by default). The link is shown once, so send it right away. Open invites are listed and can be revoked. Admins can also add a user directly in the admin panel.

Joining: the person opens the link, picks a username and password, and is signed in. A short first-run setup asks for language, what Note should call them, and their time zone (and a second key for admins). Each link works once.

category: procedural
summary: Note on Matrix: how to link Element (Matrix) and chat with Note there
---

Linking: Settings → Connections → Matrix. Enter the Matrix ID (like @name:server), press Link, then accept Note's invite in Element. Unlink removes it.

Chatting: messages in that direct chat are answered like the Chat tab. A message continues the recent conversation if it is within about an hour, otherwise a new one starts; "/new" starts a fresh one. Those threads also show in the web Chat, marked as answered on Matrix.

Notifications: once linked, "Note's messages" sends Note's check-ins and notifications to the Matrix chat, and "Ping" makes Element notify for them. Voice calls go through the same Matrix chat.

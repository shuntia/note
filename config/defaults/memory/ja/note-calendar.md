category: procedural
summary: Note のカレンダー：学校や仕事などの決まった予定、空き時間、静かにしてほしい時間の入れ方
---

場所：カレンダーは「今日」タブの中の欄。「予定を追加」でタイトル、種類、開始と終了を入れ、毎週決まった曜日にくり返すか、一度だけの日付を選ぶ。予定は削除でき、一日だけ休みにもできる。

チャットでも：「学校は平日8:15から15:30」「火曜は13時から18時までバイト」「金曜の練習は休み」。

種類：
- 固定：動かせない予定。一日の計画はこれを避けて組まれ、その間は静か（通知は終わるまで待つ）。
- 予定あり：ゆるい予定。静かにもできる。
- 空き：タスクのための時間。「空き時間を埋める」はここにだけタスクを置く。
- メモ：一日の目印で、時間を区切らない。

「今夜7時から9時は邪魔しないで」で静かな時間を作れる。アプリ自体に Google カレンダーなどとの自動同期はない。取り込みスクリプトから予定を送ることはできる。

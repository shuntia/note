category: semantic
summary: Note について：Note とは何か、できること、アプリのどこに何があるか
---

Note は自己管理のパートナー。タスク、目標、一日の計画、話したことを代わりに覚えておき、ユーザーが何もかも頭に抱えなくて済むようにする。罪悪感は与えない。連続記録も、責めることもない。

できること：チャットからタスクや目標を記録する、毎晩次の日を計画する、ちょうどいいときにチェックインする、集中して作業するセッションを回す、事実や過去の会話を覚える、連携したフィードを受信箱に取り込む、ウェブを検索する、Matrix（Element）で音声通話とチャットをする、共有リンクで一日の一部を見せる。

アプリのタブは五つ：今日（一日とカレンダー）、メモ（タスク一覧）、チャット、記憶（Note が知っていることと受信箱）、設定。上部の入力欄には何でも書ける（パソコンでは N キー）。ウェブアプリはスマホのホーム画面に追加でき、デスクトップアプリもある。

何をするにも、チャットで普通の言葉で頼むのがいちばん早い。日本語でも英語でもいい。

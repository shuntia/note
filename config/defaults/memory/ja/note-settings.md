category: procedural
summary: Note の設定：言語、名前、タイムゾーン、テーマ、パスワード、パスキー、通話の声、Note の話し方
---

設定のまとまり：セッション、一日、通知、連携、あなた、詳細（管理者には管理も）。

- 言語：「あなた」→「言語」（自動・English・日本語）。アプリ、Note の返事、通話が変わる。自動はブラウザに合わせる。
- 名前：「あなた」→「あなたの名前」（Note がユーザーを呼ぶ名前）。
- タイムゾーン：「一日」→「タイムゾーン」：この端末に合わせるか、選ぶ。
- テーマ：「あなた」→「テーマ」：システム、ライト、ダーク、空（本物の空に合わせて変わり、位置情報で日の出・日の入りも使える）。
- パスワード：「あなた」→「パスワード」。
- パスキーと認証アプリのコード：「詳細」→「パスキーとコード」。
- 通話の声：「連携」→「通話」→「声」（Matrix を連携すると出る）。
- Note の話し方：「詳細」→「Note の話し方」で、Note の人柄、計画、共有リンクの指示を編集できる。「初期設定に戻す」もある。
- 取り込み用の API トークン：「詳細」→「API トークン」。

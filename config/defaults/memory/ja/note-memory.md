---
category: procedural
summary: Note の記憶：Note がユーザーについて覚えていること、見る方法、直す方法、忘れさせる方法
---

覚えていること：長く使う事実（人、授業、習慣、好み、決めたこと）、会話ごとのまとめ、週ごとのまとめ、受信箱から届いたもの。毎晩その日の会話から学び、日付のある事実（25日の小テストなど）は過ぎれば自然に外れる。

見る：「記憶」タブに Note が知っていることが並ぶ。絞り込み（すべて・事実・出来事・受信箱）と検索欄（「Note が知っていることを検索」）がある。事実を開くと中身が読める。

直す：チャットで「それは違う、本当は〜」「〜だと覚えておいて」と言うか、事実の「それは違う」「Note にもっと伝える」を押す。忘れさせるには「それは忘れて」。Note は事実を置き換え、古いものは消さずにしまって使わなくなる。

Note は自分自身の使い方も知っているので、「〜できる？」「〜はどうやるの？」はいつでも聞ける。

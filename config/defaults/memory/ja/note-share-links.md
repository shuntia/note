category: procedural
summary: Note の共有リンク：親、パートナー、コーチなどにアカウントなしで一日の一部を見せ、Note と話してもらう方法
---

共有リンクを使うと、信頼できる人がアカウントなしで、ユーザーの一日の一部について Note と話せる。

作り方：設定 →「詳細」→「共有リンク」→「新しいリンク」。誰に向けたものか、その人との話し方についての Note への指示、見せるカテゴリ、共有する内容（計画、タスク、目標、進み具合、詳細）を選ぶ。「メモを許可」でユーザーへの伝言を残してもらえる。何日先まで見せるか、一日のメッセージ数、リンクの期限も決める。

管理：リンクのコピー、「訪問者として表示」、アクセスの記録、いつでも取り消し。訪問者側の Note は、リンクで許した範囲しか見えない。

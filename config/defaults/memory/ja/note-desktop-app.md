category: procedural
summary: Note のデスクトップアプリとスマホへの追加：ブラウザの外で Note を使う
---

スマホ：ブラウザで Note を開き、「ホーム画面に追加」（またはインストール）。アプリのように動き、プッシュ通知も受け取れる。

デスクトップ：Note のデスクトップアプリ（Linux、macOS、Windows）は Note を専用のウィンドウで開く。トレイのアイコンで表示・非表示を切り替え、「ログイン時に起動」を選べ、メニューは日本語か英語、サーバーにつながらないときはオフラインのページを出す。アプリ内にダウンロードはなく、インストーラーはサーバーの管理者が用意する。

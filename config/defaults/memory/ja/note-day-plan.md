---
category: procedural
summary: Note の一日の計画：今日タブ、夜の計画、朝の振り返り、空き時間を埋める、一日を締める
---

「今日」タブ：円が次にやることを示す。上にスワイプかスクロールすると、一日全体の線、朝の振り返り、カレンダーが出る。

夜の計画：毎晩（初期設定は3時）、Note がルーティンから次の日を組み、ブロックをずらしたり外したりし、急ぎの作業を入れ、チェックインを置き、目標を見直し、短い朝の振り返りを書く。振り返りは「今日」の下のほうに出る。設定 →「一日」→「夜の計画」でオン・オフと時刻を変えられる。

タスクを一日に入れる：「空き時間を埋める」（カレンダーの欄、またはチャットで頼む）で、「空き」の時間に未完了のタスクを置く。「いま」のタスクが先、次に緊急度と期限の順。「これを明日の午前に入れて」なら特定のタスクを置く。ブロックは開始、後回し、今日は外す、明日に移す、ができる。

一日を締める：締めの時刻（設定 →「一日」→「一日を締める」、初期設定は21:30）になると、Note がまだ残っているものを聞き、明日に持ち越すか尋ねる。時刻を空にすると止まる。

設定 →「一日」→「ルーティンとブロック」で、どのルーティンで知らせるかを選ぶ。

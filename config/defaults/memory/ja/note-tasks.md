summary: Note のタスク：追加、サイズ、期限、緊急度、分割、完了・取りやめの方法
---

追加：チャットで言う（「書類を送るのを忘れないようにして」「タスク追加：4章を読む」）と Note が記録する。または「メモ」タブ上部の欄にタイトルを入れて「タスクを追加」。

サイズ：タスクには5分単位の長さがある（「1時間くらいかかる」）。長いものは空き時間に置くときに分けて入る。

期限：「金曜まで」で締め切りが付く。やる日ではなく、終わっていなければならない日。一覧には「今日まで」「明日まで」「期限切れ」などと出る。

緊急度：低・普通・高。「急ぎ」と言えば Note が高にする。ユーザーが上げたものを Note が下げることはない。期限切れか2日以内が期限のものは差し迫ったものとして扱う。

分割：「細かく分けて」で、タスクをいくつかに分け、それぞれに長さを付ける。分けたものをさらに分けることもでき、4段まで入る。タスクの長さは分けたものの合計になり、分けたものの期限は元のタスクより後にならず、全部終わればタスクも完了になる。あとから足すこともできる。作業セッションは分けたものを順に進める。

「メモ」タブでは、タスクが「今」（最大3つ）、近いもの（急ぎ、または7日以内に期限や予定があるもの）、たたまれた「後で」、「今日の完了」、「目標」に分かれる。各行のメニューで完了、中止、編集、「今」「後で」への移動、開始、通知方法（なし・チャット・通知）を選べる。完了と中止は元に戻せる。「消して」と言えば完全に削除する。

---
category: procedural
summary: Note のチェックイン：Note から声をかけるしくみ、手が止まったときの声かけ、回数の変え方
---

チェックイン：一日の計画にあるルーティン（朝のチェックインなど）が、チャットのその日のスレッドに質問を書く。ユーザーはそこに返事をするだけ。通知でも届き、Matrix を連携していればそちらにも届く。

Note は自分の判断で、あとでもう一度様子を見ることもある。タスクがどうだったか聞く、返事がなければ声をかける、など。そのとき何か言うこともあれば、必要なければ黙っていることもある。チャットで「3時に声をかけて」と言えば置ける。

回数：設定 →「通知」→「1日あたりの Note からのチェックイン」で一日の上限を決める（初期設定は4回）。もっと必要だと Note が思ったら、先に聞く。「チェックイン」のスイッチでルーティンの通知を止められる。

手が止まったときの声かけ：しばらく操作がなく（初期設定は20分）、Note が覚えておいていることがまだ残っていると、軽く一度声をかける。設定 →「通知」→「手が止まったら知らせる」で時間を変えたり止めたりできる。作業セッション中、静かにする予定の間、一日を締める時刻のあとには来ない。

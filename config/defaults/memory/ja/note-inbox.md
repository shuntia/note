summary: Note の受信箱：連携したフィード（授業サイト、学校、ワークスペース、メーリングリスト）と、届いたものの扱い
---

受信箱には、授業サイト、学校のポータル、チームのワークスペース、メーリングリストなど、連携した情報源から届いたものが集まる。「記憶」タブの「受信箱」にあり、更新ボタンがある。

届いたものごとに Note が一つ決める：覚える（日付、決まり、どこに何があるかなど役に立つ事実を残し、日付のあるものは過ぎれば消える）、タスクにする（課題は期限、サイズ、ステップ付きのタスクになる）、何もしない。それぞれにどうなったかが表示される。更新されたものが届くと、前に覚えた内容を置き換える。

フィードの連携：アプリに連携ボタンはない。取り込みスクリプトが API トークンで送る。トークンは設定 →「詳細」→「API トークン」で作る。取り込みの設定はサーバーの管理者が行う。

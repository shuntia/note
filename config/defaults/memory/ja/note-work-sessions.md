---
category: procedural
summary: Note の作業セッション・ポモドーロ：タスクに集中するセッションの始め方、休憩、終わり方
---

始め方：「今日」タブで円をタップ（「作業を開始」）、ブロックの開始、または「メモ」タブでタスクの行メニューから開始。新しく始めると、動いている別のセッションは終わる。

実行中：円が残り時間のゲージになる。タップで一時停止、休憩、ステップのあるタスクなら「このステップは完了」、終わったら下にスワイプ。Note は途中と終わり近くに自分から様子を聞き、終わったあとにどうだったか尋ねる。作業した時間はタスクに記録される。

ポモドーロ：設定 →「セッション」→「ポモドーロ」でラウンド制にする（初期設定は作業25分・休憩5分、どちらも変えられる）。作業と休憩の切り替わりを Note が知らせる。

設定 →「セッション」では、終わったときの通知や、残り時間と経過時間の表示も選べる。

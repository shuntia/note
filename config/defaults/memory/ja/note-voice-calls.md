---
category: procedural
summary: Note の音声通話：Matrix・Element X で Note に電話する方法と、Note から電話してもらう方法
---

準備：まず Matrix アカウントを連携する（設定 →「連携」→ Matrix）。そうすると Element X で通話できる。

Note に電話する：Element X の Note とのチャットで音声通話を始める。Note は数秒で出て、ユーザーが先に話すのを待つ。ユーザーが話した言語（日本語か英語）で答える。チャットでできることは通話でもできる：タスクの追加、計画の確認、調べもの。調べものは話している間に裏で進み、Note が話している途中でもいつでも割り込める。「じゃあね」「以上」などで終わり、Note があいさつして切る。通話は30分で終わる。

Note から電話してもらう：設定 →「連携」→「通話」→「電話で知らせる」で、急ぎのとき・チェックイン・しない を選ぶ。「電話をかける」で試せる。同じ場所で Note の声を選び（タップで試聴）、準備完了の音のオン・オフも切り替えられる。

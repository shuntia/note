---
category: procedural
summary: Matrix での Note：Element（Matrix）を連携して Note とチャットする方法
---

連携：設定 →「連携」→ Matrix。Matrix ID（@name:server のような形）を入れて「連携」を押し、Element で Note の招待を承認する。「連携を解除」で外せる。

チャット：そのダイレクトチャットへのメッセージには、チャットタブと同じように答える。1時間ほど以内なら直前の会話の続きになり、それより空けば新しい会話になる。「/new」で新しく始められる。その会話はウェブのチャットにも、Matrix で答えた印付きで出る。

通知：連携したあと「Note からのメッセージ」をオンにすると、チェックインや通知が Matrix のチャットに届き、「通知」をオンにすると Element が音で知らせる。音声通話も同じ Matrix のチャットから。

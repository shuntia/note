summary: Note の通知：プッシュ通知のオンにし方と、タスクごとの知らせ方
---

オンにする：設定 →「通知」→「このスマホにプッシュ通知」（スマホやブラウザごとに）。「テスト通知を送る」で確かめられる。通知をタップすると、その会話が開く。

届く先：アプリを開いていればそこ、次にプッシュ通知、Matrix を連携していればそちら。静かにする予定の間は、終わるまで待つ。

タスクごと：タスクやブロックが始まるときの知らせ方は三つ：なし（静か）、チャット（その日のスレッドに一行）、通知（初期設定）。タスクの行メニュー、ブロックの「知らせて」、またはチャット（「読書のブロックは知らせなくていい」）で変えられる。

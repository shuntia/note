summary: Note の作業メモとメモタブ：Note が覚えておくちょっとしたこと、近いものと「あとで」
---

覚えておくこと：「〜を覚えておいて」「銀行に折り返すのを忘れないで」と言うと、Note はそれを作業メモとして書く。作業メモはどの会話でも通話でも Note が読む短い一行で、「金曜まで」のように時間帯が付くこともある。ちょうどいいときに話に出し、手が止まっているときに声をかけることもあり、片付いたと聞けば消す。毎晩、時間を過ぎたものや3日間触れていないものは整理され、まだ大事なら長期の記憶に残し、そうでなければ手放す。時間や手間がかかるものはタスクにする。

「メモ」タブはタスク一覧：上に「いま」、続いて近いもの（急ぎ、または7日以内に期限や予定があるもの）、たたまれた「あとで」、「今日の完了」、「目標」。上の欄でタスクの追加や検索ができ、カテゴリで絞り込める。

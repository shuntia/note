category: procedural
summary: Note のメモとメモタブ：Note が覚えておくちょっとしたこと、近いものと「あとで」
---

覚えておくこと：「〜を覚えておいて」「銀行に折り返すのを忘れないで」と言うと、Note はそれを自分用のメモとして持つ。メモはどの会話でも Note が読む下書き帳。ちょうどいいときに話に出し、手が止まっているときに声をかけることもあり、片付いたと聞けばチェックする。時間や手間がかかるものはタスクにする。

「メモ」タブはタスク一覧：上に「いま」、続いて近いもの（急ぎ、または7日以内に期限や予定があるもの）、たたまれた「あとで」、「今日の完了」、「目標」。上の欄でタスクの追加や検索ができ、カテゴリで絞り込める。

---
category: procedural
summary: Note の招待（管理者向け）：誰かを Note に招待する方法と、参加したときに起きること
---

招待できるのは管理者だけ。

招待の作り方：設定 →「管理」→「管理パネル」（パスキーか認証アプリのコードを求められる）→ 招待 →「招待リンクを作る」。ユーザー名の候補、管理者にするかどうか、何日有効にするか（初期設定は7日）を選べる。リンクは一度しか表示されないので、すぐ送る。未使用の招待は一覧に出て、取り消せる。管理パネルからユーザーを直接追加することもできる。

参加：招待された人はリンクを開いてユーザー名とパスワードを決め、そのままサインインする。最初に短い設定があり、言語、Note に呼んでほしい名前、タイムゾーンを聞かれる（管理者には二つ目の鍵も）。リンクは一度だけ使える。
